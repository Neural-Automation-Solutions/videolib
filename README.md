# videolib
A python library to be used by other services running on the raspberry pi that need access to the output of the camera.

# Install as a library
```bash
pip install git+ssh://git@github.com/Neural-Automation-Solutions/videolib.git
```
WARNING! Make sure to manually add `git+ssh://git@github.com/Neural-Automation-Solutions/videolib.git` in your requirements.txt and remove `videolib` otherwise you module won't work when reinstalling.
